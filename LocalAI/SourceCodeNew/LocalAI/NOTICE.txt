    Qwen3-0.6B-LICENSE.txt beside this file is the Apache 2.0 text for the model

    Qwen, or Llama, Phi, Gemma, Mistral - replace it: Gemma and Llama in
    particular have their own terms and are not Apache 2.0.

    MODIFICATIONS. Apache 2.0 requires that changes be stated, and converting
    weights to ONNX counts as a change. If you distribute a converted model
    alongside this extension, a statement of this shape is what is wanted:

      - converted from the original safetensors to ONNX, using the model builder
        from onnxruntime-genai (`onnxruntime_genai.models.builder`)
      - stored at <fp16 / int4> precision
      - packaged with a genai_config.json describing the decoder inputs/outputs
        and the generation defaults
      - no retraining, fine-tuning or distillation; behaviour is that of the
        published model subject only to conversion rounding

    Adjust it to what you actually did.

3. Microsoft Visual C++ runtime
-------------------------------

    Shipped in this package:

      msvcp140.dll      msvcp140_1.dll
      vcruntime140.dll  vcruntime140_1.dll

    Copyright (c) Microsoft Corporation. These are the redistributable files of
    the Microsoft Visual C++ Runtime, deployed application-locally beside the
    llama.cpp binaries that import them.

    WHY THEY ARE HERE. llama.dll, ggml.dll and every ggml-cpu-*.dll link to this
    runtime dynamically. The process that hosts Peakboard extensions ships none
    of its own, so without these it uses whatever is installed on the machine.
    A stock Peakboard Box has no Visual C++ runtime at all, and the load fails
    with 0x8007007E - a message naming neither the DLL nor the cause.
    A copy beside the binaries takes precedence, so shipping a current one makes
    the extension work on an unmodified Box.

    REDISTRIBUTION. These files are on Microsoft's redistributable list and are
    covered by the licence terms of the Visual Studio installation they were
    taken from, which permit application-local redistribution with a program
    that uses them. Anyone repackaging this extension commercially should
    confirm those terms against their own Visual Studio licence rather than rely
    on this note.

    VERSION. 14.51.36247.0. Keep it current when rebuilding: the runtime is
    backward compatible, so a newer copy also serves anything else loaded into
    the same host process, but an older one would not.


4. Not shipped: GPU backends
----------------------------

    This build is CPU-only.

    llama.cpp publishes Vulkan, SYCL, CUDA and ROCm builds, all MIT, and any of
    them could be bundled instead. None is, for a measured reason rather than a
    licensing one: on a Peakboard Box the Gen11 integrated GPU returned
    numerically wrong output under DirectML, and no GPU path on that hardware
    has been shown correct. A GPU build is a thing to prove, not to ship
    hopefully. See the README, "Why CPU only".

    Earlier versions of this extension used ONNX Runtime GenAI, where the GPU
    option was Microsoft.AI.DirectML - NOT MIT, carrying terms restricting use
    to Windows and Xbox. That consideration no longer applies: llama.cpp's GPU
    backends carry the same MIT licence as the rest of it.
