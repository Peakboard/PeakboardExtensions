1. Language model - NOT INCLUDED
--------------------------------

    The extension ships no weights. You point ModelPath at a model folder you
    obtain or build yourself (see README, "Getting a model"), and that model
    carries its own licence, separate from this extension's.

    Qwen3-0.6B-LICENSE.txt beside this file is the Apache 2.0 text for the model
    the extension was developed against:

      Qwen3-0.6B
      Copyright (c) Alibaba Cloud / the Qwen team
      Licensed under the Apache License, Version 2.0
      https://huggingface.co/Qwen/Qwen3-0.6B

    It is included as a starting point. If you ship a different model - a larger
    Qwen, or Llama, Phi, Gemma, Mistral - replace it: Gemma and Llama in
    particular have their own terms and are not Apache 2.0.

    MODIFICATIONS. Apache 2.0 requires that changes be stated, and converting
    weights to ONNX counts as a change. If you distribute a converted model
    alongside this extension, a statement of this shape is what is wanted:

      - converted from the original safetensors to ONNX, using the model builder
        from onnxruntime-genai (`onnxruntime_genai.models.builder`)
      - stored at <fp16 / int4> precision
      - packaged with a genai_config.json describing the decoder inputs/outputs
        and the generation defaults
      - no retraining, fine-tuning or distillation; behaviour is that of the
        published model subject only to conversion rounding

    Adjust it to what you actually did.

3. Not shipped: DirectML
------------------------

    This build contains no DirectML and is CPU-only.

    Swapping the package reference from Microsoft.ML.OnnxRuntimeGenAI to
    Microsoft.ML.OnnxRuntimeGenAI.DirectML adds Microsoft.AI.DirectML, which is
    NOT MIT. It carries the MICROSOFT SOFTWARE LICENSE TERMS for DirectX Machine
    Learning, which restrict use to Windows and Xbox and include a binding
    arbitration clause. That flavour should not be distributed without a legal
    review.

    It is also of no use on a Peakboard Box: DirectML returns numerically wrong
    output on the Box's Gen11 integrated GPU. See the README, "Why CPU only".
