3. Not shipped by default: DirectML
-----------------------------------

    The default build (Backend=cpu) contains no DirectML.

    Building with `-p:Backend=dml` adds Microsoft.AI.DirectML, which is NOT MIT.
    It carries the MICROSOFT SOFTWARE LICENSE TERMS for DirectX Machine Learning,
    which restrict use to Windows and Xbox and include a binding arbitration
    clause. That flavour should not be distributed without a legal review.

    It is also of no use on a Peakboard Box: DirectML returns numerically wrong
    output on the Box's Gen11 integrated GPU. See bench/RESULTS.md.
